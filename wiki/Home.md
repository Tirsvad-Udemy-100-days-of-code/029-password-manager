# Home

MyPass is a small desktop password manager made with Python and Tkinter, as Day 29 of the Udemy course *100 Days of Code: The Complete Python Pro Bootcamp*. It generates a strong random password, keeps it together with the website and email, and copies it to the clipboard.

## Features

- Generates a password of 8 to 10 letters, 2 to 4 symbols and 2 to 4 digits, shuffled.
- Copies the generated password to the clipboard.
- Saves website, email and password to `data.txt` after you confirm.
- Refuses to save when the website or the password is empty.
- No runtime dependencies: only the Python standard library.
